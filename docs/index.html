Bell Guard

Bell lends against Coinbase tokenized stocks and never liquidates on a single price print: the next print has to confirm it. Bell Guard turns that one print of warning into protection. A Reactive Network contract sees the falling print and calls back to Base, where the guard pays down the borrower's debt before the confirming print can land.

The loop

Every step is an on-chain transaction. Times are read from Base's BaseTime predeploy, which gives each 200 ms block a millisecond timestamp.

Base Sepolia

1 · A falling print

A Bell market records a new price round for a stock and emits Observed. Bell still prices liquidations at the higher of the last two prints, so nobody can be liquidated yet.

→
Reactive Lasna

2 · BellGuardReactive

Keeps the last print of every stock it watches. If the new print is lower, it requests a callback to Base. Rises and flat prints cost nothing more. If a sweep runs out of gas, it asks for the rest.

→
Base Sepolia

3 · BellGuard

Values each protected position at the lower print, which is what the confirming print will make real. Below the borrower's trigger, it repays from the borrower's own tUSD up to their budget, back to their target.
